# Gmailラベル → スプレッドシート自動記録（Google Apps Script）

Gmailで特定のラベル（例：「請求書」）が付いたメールを**1時間ごとに自動チェック**し、
**差出人・件名・受信日時・本文の冒頭100文字**をスプレッドシートに1行ずつ追記する仕組みです。
**同じメールは二重に記録しません。**

初期設定は `setup()` 関数を1回実行するだけで、管理表と自動実行の設定（トリガー）が作られ、既存のメールもまとめて記録されます。

## できること

| 機能 | 内容 |
|---|---|
| ラベルで対象を指定 | Gmailでラベルを付けるだけ。Gmailの「フィルタ」と組み合わせれば、ラベル付けも自動化できる |
| 1時間ごとに自動記録 | 差出人・件名・受信日時・本文の冒頭100文字を、古い順に1行ずつ追記 |
| 二重記録の防止 | メールごとの固有ID（メールID）を記録し、記録済みのメールは飛ばす |
| Gmailへのリンク | 各行の「Gmailで開く」から、元のメールをすぐに開ける |
| 日本語メール対応 | UTF-8・ISO-2022-JP・Shift_JIS などの文字コードに合わせて本文を読む。HTMLメールはタグを除いて記録 |
| 安全設計 | Gmailは**読み取り専用**の権限だけを使う（メールの送信・削除・変更はできない）。件名が「=」で始まっても数式として動かない |

## 使う人のメリット

- **転記作業がゼロ**：請求書メールを開いて、表にコピペする作業が不要になる
- **見落とし・二重計上の防止**：届いた請求書が一覧にそろう。同じメールが2回入ることもない
- **経理・月末処理が楽になる**：表を差出人や受信日時で並べ替えたり絞り込んだりして、支払い予定の確認に使える
- **安心して導入できる**：読み取り専用の権限なので、メールが消えたり勝手に送信されたりする心配がない
- **追加費用なし**：Googleアカウントだけで動く

## 導入手順

### 必要なもの
- Googleアカウント
- Node.js（[公式サイト](https://nodejs.org/ja)からインストール）

### 手順
1. Gmailで、記録したいラベル（初期設定：「請求書」）を作り、対象のメールに付けておく
2. Apps Script APIを有効にする
   https://script.google.com/home/usersettings を開き、「Google Apps Script API」をオンにする
3. このフォルダで必要な道具を入れ、Googleにログインする
   ```bash
   npm install
   npx clasp login
   ```
4. GASプロジェクトを作り、コードをアップロードする
   ```bash
   npx clasp create --type standalone --title "Gmail記録" --rootDir src
   npx clasp push --force
   ```
   ※ `create` で `src/appsscript.json` が上書きされた場合は、元の内容に戻してから `push` してください
5. GASの編集画面を開く（`npx clasp open-script`）
6. 関数のプルダウンで `setup` を選び「▷ 実行」→ 権限を許可する
   （「Googleで確認されていません」と出たら「詳細」→「〜に移動」）
7. 実行ログに表示される「スプレッドシートURL」を開く

`setup()` は2回目以降に実行しても重複して作られません。すぐに記録したいときは `checkMail()` を手動で実行できます。

## カスタマイズできる点

`src/Code.js` 冒頭の `CONFIG` を書き換えて `npx clasp push` するだけで変更できます。

| 変えたいこと | 場所 |
|---|---|
| 対象のラベル（「経理/請求書」のような階層付きも可） | `CONFIG.LABEL_NAME` |
| 本文を記録する文字数 | `CONFIG.BODY_LENGTH` |
| チェック間隔（1・2・4・6・8・12時間） | `CONFIG.INTERVAL_HOURS`（変更後はトリガーの作り直しが必要） |
| 管理表のファイル名・シート名 | `CONFIG.SHEET_FILE_NAME` / `SHEET_NAME` |
| 1回に記録する最大件数 | `CONFIG.MAX_PER_RUN` |

さらに拡張する例：
- 本文から金額・支払期限・請求書番号を取り出して列に分ける
- 添付PDFをGoogleドライブの月別フォルダに保存する
- 新しい請求書が来たらSlack・Chatworkに通知する
- 複数のラベルを別々のシートに振り分ける

## 使用している権限

Gmailの読み取り（読み取り専用）、スプレッドシートの作成・編集、トリガーの作成の3つだけです。
Gmailの操作には、読み取り専用の権限で使える公式の「Gmail API」（無料）を使っています。GASで一般的な `GmailApp` は、メールの送信・削除までできる強い権限を求めるため、使っていません。
