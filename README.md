# 業務自動化ポートフォリオ（Google Apps Script）

Googleフォーム・スプレッドシート・Gmailを組み合わせた、業務の自動化デモ集です。
どれも Googleアカウントだけで動き、追加費用はかかりません。

| No. | 作品 | できること |
|---|---|---|
| 01 | [問い合わせフォーム自動通知](01-form-notify/) | フォームの問い合わせを管理表に自動記録し、Gmailに即時通知。対応状況（未対応／対応中／対応済み）で返信漏れを防止 |
| 02 | [Gmailラベル → スプレッドシート自動記録](02-mail-to-sheet/) | 「請求書」などのラベルが付いたメールを1時間ごとに表へ追記。二重記録なし、Gmailは読み取り専用の権限だけで安全に扱う |
| 03 | [CSV自動整形 → スプレッドシート出力](03-csv-format/) | ドライブのフォルダに置いたCSVを、列の並び・日付・全角/半角を統一し、重複行を削除して出力。UTF-8/Shift_JIS対応、元データは変更しない |
| 04 | [請求書PDFの自動作成＋Gmail下書き](04-invoice-pdf/) | 請求一覧の行から請求書PDFを作ってドライブに保存し、宛先ごとにGmailの下書きを作成（送信はしない）。作成済みの行は二重に作らない |
| 05 | [予約フォーム → Googleカレンダー自動登録](05-form-to-calendar/) | 予約の申し込みを専用カレンダーに自動登録。同じ時間帯に予定があれば登録せず「要確認」として記録 |
| 06 | [問い合わせのAI自動仕分け＋返信の下書き](06-inquiry-ai-triage/) | Gemini APIで分類・緊急度・要約・返信文を作り、Gmailに下書きを作成（送信はしない）。AIの応答は検証し、おかしいときは「要確認」 |

各フォルダの README に、導入手順とカスタマイズ方法を載せています。
